# RAG V3 Final Experiment / Promotion / Regression Report

## 1. Final Architecture

Production default remains: history-based rewrite -> BGE-M3 dense/sparse Weighted Hybrid (0.8/0.2) -> Candidate10 -> Fixed Top5 token-aware context -> qwen-flash generation -> sources/SSE/Mongo history. Explicit RRF, gte-rerank-v2, HyDE and Dynamic Selector remain executable optional stages with fallbacks, not defaults.

## 2. Frozen Dataset / Hashes

- Dataset: 110 queries (90 answerable, 20 no-answer), SHA-256 `6c99b11ffaa35142bc6dd3f7fd483a04fe090cfbb3210772f0db8b5cd5cd7634`.
- Corpus manifest SHA-256: `0086b5357ff0c88cc0a5a78b660f8656d2b8814a133303a24dc4f08109ec682d`.
- Collection: `rag_eval_v2_chunks`; embedding: `BAAI/bge-m3`.
- Frozen data and collection were read-only. No post-result tuning was performed.

## 3. Environment Acceptance

Docker Engine, etcd, MinIO, Milvus and MongoDB were healthy; `localhost:19530` was reachable. MinIO host exposure is `localhost:19000`, while the unchanged container endpoint is `minio:9000`. Real qwen-flash and gte-rerank-v2 minimal calls passed with TLS verification enabled.

## 4. Experiment A — Production Baseline

Recall@1/3/5 = 0.6481/0.8574/0.8944; MRR@5 = 0.8204. Context mean = 4.88 chunks / 2582 approximate tokens. Original run retrieval/context P50/P95 = 104.13/150.14 ms.

## 5. Dynamic Context (A vs C)

C produced the same retrieval metrics, mean context count and token count as A under frozen parameters. It did not provide the required context reduction and therefore is not promoted.

## 6. Explicit RRF (A vs E)

E Recall@1/3/5 = 0.6389/0.8611/0.9056; MRR@5 = 0.8065; P50/P95 = 384.20/530.46 ms. Recall@5 improved, but Recall@1/MRR regressed and latency increased. Decision: KEEP_OPTIONAL / REJECT_DEFAULT.

## 7. Real Rerank (A vs B)

Real gte-rerank-v2 B Recall@1/3/5 = 0.6667/0.8630/0.9056; MRR@5 = 0.8204. There were 8 MRR improvements, 9 degradations and 73 unchanged answerable queries. Total retrieval/context P50/P95 = 706.52/883.40 ms. Paired total-latency overhead proxy P50/P95 = 603/765 ms (not a separately instrumented stage latency). `v2q030` remained a severe regression: baseline relevant rank 2 became a Top5 miss. Small early-recall gains, unchanged MRR, inconsistent per-query movement and remote latency do not support default promotion. Decision: KEEP_OPTIONAL.

## 8. Targeted HyDE

Scope: all 18 `paraphrase_colloquial` queries plus all 20 no-answer queries. On the answerable subset, normal vs HyDE Recall@1 was 0.5000 vs 0.5556; Recall@3/5 both remained 0.8333; MRR@5 was 0.6574 vs 0.6852. Two queries improved, one degraded and 15 were unchanged. HyDE generation P50/P95 = 1305.94/1661.57 ms; total P50/P95 = 1631.10/2098.83 ms. Lexical proxy flagged 19/20 no-answer hypotheses; manual review found unsupported concrete assertions in all 20, including invented model specifications, numeric limits, legal rules and root causes. These are hypothesis drift, not final-answer hallucinations. Decision: REJECT_DEFAULT / KEEP_OPTIONAL for controlled research only.

## 9. Generation Evaluation

All 110 answers were generated by real qwen-flash with zero API errors. Diagnostic proxies on the 90 answerable cases: answer correctness 0.7333, faithfulness 0.5477, source/citation coverage 0.9111, context relevance 0.2300. LLM P50/P95 = 933.45/2315.85 ms. These are deterministic/reference-based diagnostics, not human accuracy, semantic accuracy, or RAGAS gold-standard results. Locator extraction was corrected to read actual `<!-- locator: ... -->` metadata without changing Frozen data.

No-answer results after correcting explicit-refusal detection: 14/20 supported refusals (70%), 5/20 unsupported factual claims (25%), 1/20 uncertain/review (5%).

## 10. Manual Review

Ten high-score, ten low-score and five no-answer cases were inspected. High-score facts were generally correct, but at least one high-score response invented `example.com` image URLs. Several low-score answers were semantically correct (`v2q044`, `v2q087`, `v2q045`) despite zero correctness proxy, while others exposed genuine retrieval misses/version confusion. Faithfulness missed fabricated image URLs; citation correctness measures selected-source/locator coverage rather than claim-level citation entailment. Consequently correctness, faithfulness and citation scores are DIAGNOSTIC ONLY. Context relevance is valid as a locator-based precision-like measure but does not measure semantic entailment.

## 11. Failure Analysis

The largest retrieval weakness is low context precision and category-specific misses (table, paraphrase, version confusion), not candidate Recall@5 alone. The largest generation risks are unsupported details and fabricated image URLs. Automatic failure counts are diagnostic: 97 unfaithful-proxy, 50 incorrect-proxy, 8 citation mismatch and 5 no-answer false claims. Root-cause labels remain hypotheses because the proxy/manual disagreement is material. Adding rerank/HyDE did not reliably solve these issues.

## 13. Final Production Default

No strategy earned promotion. The final default is unchanged: history rewrite -> Weighted Hybrid 0.8/0.2 -> Candidate10 -> Fixed Top5 -> qwen-flash. This is an evidence-based non-change, not a missing V3 result.

## 14. Final Regression

Fresh 110-query regression: Recall@1/3/5 = 0.6481/0.8574/0.8944; MRR@5 = 0.8204; retrieval/context P50/P95 = 75.89/120.85 ms. Metrics exactly match A; latency variance is expected warm-state/runtime variance. Tests: Parent 9, Phase1 14, Phase2 25, Phase3 4, acceptance 12, integration 2 = 66 passed, 0 failed. Compile and `git diff --check` passed. Real Mongo and Milvus integrations passed.

## 15. Reliability / Fallback Behavior

Rewrite failure -> original query; HyDE failure -> normal hybrid; rerank failure -> original candidates; history failure -> stateless/read-only continuation where safe; Mongo write failure -> answer survives; Milvus/embedding/generation failures -> structured error. SSE timeout/error/close behavior is covered by tests.

## 16. Known Limitations

- Generation proxies disagree materially with manual semantics and cannot be called accuracy.
- Sources are returned separately; claim-level citation entailment is not implemented/evaluated.
- The prompt can still emit fabricated image URLs and lacks a production no-answer gate.
- HyDE target subset is category-based and small; rewrite challenge is development-only.
- Rerank stage-specific latency was not separately captured in the artifact; paired end-to-end overhead is reported transparently.

## 17. Resume-safe Evidence

The project can honestly claim a real frozen 110-query BGE-M3/Milvus regression, real DashScope rerank and generation calls, targeted HyDE with saved hypotheses, no-answer analysis, deterministic proxy/manual disagreement analysis, optional-stage fallbacks, and evidence-based non-promotion.

## 18. Claims That Must NOT Be Made

Do not claim human accuracy, semantic accuracy, RAGAS gold-standard evaluation, production no-answer safety, HyDE/rerank/RRF superiority, parent-context retrieval improvement, or claim-level citation correctness. Do not present diagnostic proxy scores as ground truth.
